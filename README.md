# Wearable BioNode
BioNode is a 30×30 mm biosignal smartwatch on an NXP i.MX heterogeneous-core SoC (Cortex-A running Linux with a touchscreen GUI, Cortex-M for always-on sensing). Features a 24-bit ECG/EMG, SpO₂/HR, EDA, temp, and motion with a emergency beacon feature: GNSS location over BLE to a phone, with LoRa and satellite fallback. Dual-PCB HDI stack.
